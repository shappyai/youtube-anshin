# 公式素材取得失敗ポリシー（恒久）

`official_capture_failed` は、公式ページ・公式PDF・公式画像の取得、切り出し、または検証に失敗した状態を表す。これは、読める部分だけを抜き出して公式素材として表示してよい、という意味ではない。

## fail closed

- `official_capture_failed` がsceneまたはassetに付いている間は、rendererは抽出途中の文字、OCR結果、部分的な画像を公式素材として描画しない。
- render gateは失敗を記録し、次の確認が終わるまでdraft生成を止める。
- 復旧後は、取得元URL、確認日、使用したページまたはPDFページ、採用範囲、SHA-256を `sources.md` と `media_manifest.csv` に残す。

## 復旧の優先順位

1. 同じ公式URLから公式ページまたは公式PDFを再取得し、実際の該当箇所を再切り出しする。
2. 同じ公式ソース内の別表示（HTML版、別ページ、別の公式画像）で確認する。
3. 公式原文と完全一致する短い引用を、出典ラベルとURLを伴うquote assetとして使用する。
4. 公式文面を再現できない場合は、公式UI・公式画像として見せず、出典を伴うsemantic sceneへ切り替える。

再取得前に、部分的な抽出文字を「公式の画面」や「公式資料」として採用してはならない。Episode012 SCENE-007はこの規則に従い、公式PDFで確認できる一文を正確な短い引用として採用した。
