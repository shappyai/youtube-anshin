# 【マイナアプリ】マイナポータルアプリはどう変わった？今やること3つ

マイナポータルアプリの名前やアイコンが変わり、「何が変わったの？」「入れ直したほうがいいの？」と戸惑っている方へ。

この動画では、2026年8月30日時点のデジタル庁・公式ストア・公式FAQの情報をもとに、次の内容を確認します。

- 新しいマイナアプリとは何か
- マイナポータルアプリとデジタル認証アプリの関係
- マイナポータルというサービス自体はなくなっていないこと
- すでに使っている人のアップデート方法
- 新しく使う人の利用登録と端末ロック
- App Store・Google Playで本物を確認する方法
- 偽物アプリやフィッシングへの注意

マイナンバーカードの読み取りや暗証番号の入力は、この動画では実演していません。個人情報にかかわる手続きは、ご自身のスマートフォンで公式画面の案内に沿って行ってください。
