# Episode 013 research

確認日: **2026-09-06**  
調査対象: LINE公式ヘルプ、Apple公式サポート、Google公式ヘルプ  
調査方法: 公式ページ本文をブラウザで直接確認。第三者記事・競合動画は主要Factの根拠に使用していない。

## 1. この動画で使える確定Fact

### サポート終了予定

LINE公式のお知らせは、2026年11月上旬に、LINEアプリのうち次のバージョンのサポートを終了する予定と案内している。

- iOS／iPadOS: LINE 14.6.3未満
- Android: LINE 14.4.6未満

「LINEが全部使えなくなる」ではなく、「対象の古いアプリバージョンがある」という表現に限定する。日付は「11月上旬の予定」とし、公開前に再確認する。

### OSとの関係

同じLINE公式案内では、iOS／iPadOS 15.0以上、Android 8.0以上の環境で、LINEをそれぞれ14.6.3以上／14.4.6以上に更新すれば、引き続き利用できると説明している。

iOS／iPadOS 14.8.1以下、Android 7.1.2以下では、OSをiOS／iPadOS 15.0以上、Android 8.0以上へ更新し、その後LINEを最新版へ更新する手順が示されている。

### 更新できない場合

OSまたはLINEを更新できない場合、LINE公式はLINEの動作環境を満たす別の端末での利用を検討するよう案内している。ここから「必ず買い替え」とは言わず、「更新できない場合に、対応端末への移行を検討」とする。

### LINEバージョンの確認

LINE公式の手順は、メイン端末で「ホーム → 設定 → LINEについて → 現在のバージョン」。表示された数字をそのまま確認する。画面名や順序はアプリの更新で変わる可能性をshotlistに明記する。

### OSバージョンの確認

- Apple公式: iPhone／iPadの「設定 → 一般 → 情報」でiOS／iPadOSのバージョンを確認。
- Google公式: Androidの「設定 → デバイス情報」または「タブレット情報 → Androidバージョン」で確認。端末によってメニュー名が異なる。

### アプリ・OSの更新

- Apple公式: App Store → 画面上部のアカウント → アプリのアップデート → LINEの「アップデート」。OSは「設定 → 一般 → ソフトウェアアップデート」。
- Google公式: Google Play → プロフィール → アプリとデバイスの管理 → アップデート利用可能 → LINEの「更新」。OSは「設定 → システム → ソフトウェアアップデート」。Androidの更新時期や表示は端末メーカー・通信会社で異なる。

## 2. 混同しない情報

LINEの利用環境ページには、最新版を利用できる推奨環境としてiOS 18.0以上、Android 11.0以上も掲載されている。一方、11月上旬のサポート終了告知では、iOS／iPadOS 15.0以上、Android 8.0以上を基準にした更新手順が示されている。

動画では次のように分ける。

- 今回の11月対応でまず見る下限: iOS／iPadOS 15.0、Android 8.0
- LINE最新版の推奨環境: iOS 18.0、Android 11.0

最新版の実際のアプリ番号は更新されるため、動画内では使わず、今回のサポート終了の判定に必要な下限だけを表示する。

## 3. ケース分岐

| ケース | 確認結果 | 伝える対応 |
|---|---|---|
| A | LINE・OSとも基準以上 | 今回のために急いで買い替えない。通常の更新確認を続ける |
| B | LINEが古いがストアに更新がある | LINEを更新し、バージョンを再確認 |
| C | LINE更新にOS更新が必要 | OSを先に更新し、その後LINEを更新 |
| D | OSもLINEも更新できない | 公式案内を確認し、対応端末への移行を検討。メーカー・通信会社にも相談 |

## 4. 未確認・公開前に再確認すること

- 「11月上旬」の具体的な実施日: 公式ページが予定表現のため、公開直前に再確認。
- 実機に表示されるLINE／OSの数字、メニュー名、ストアの表示: Phase Bの実機キャプチャ時に確認。
- iPhoneの機種ごとのiOS上限、Android各メーカーの更新可否: 個別端末ごとに異なるため、この動画では機種名を一般化しない。
- 2026-09-10 Apple Event後の公開順: 人間が再判定。
