# Episode 013 analytics plan

公開後に比較する指標を、企画段階で固定する。数値目標は公開前に推測せず、Episode 012・同時期のLINE動画との相対比較で見る。

## 視聴行動

- Home CTR: 「11月に使えなくなる？」が不安を煽りすぎず、自己関連性を作れているか。
- Search fit: 「LINE 11月」「LINE 14.6.3」「Android 14.4.6」「LINE バージョン 確認」の検索流入。
- 0〜15秒維持率: 「全員ではありません」「対象は古いLINE・OS」を聞く前に離脱していないか。
- 25秒時点の維持率: 実際のLINEバージョン確認に入れているか。
- 1 / 3、2 / 3、3 / 3の章到達率: 3つの確認が長く感じられていないか。
- まとめ到達率: ケースDの更新不能・別端末案内まで見られているか。

## 視聴者の自己解決

- コメント内の「自分のLINEは対象か」「iPhone／Androidの機種名」「更新できた／できない」の記述。
- 同じ質問の反復を、次回の補足動画候補として記録する。
- 「買い替えが必要だと思っていたが確認できた」という安心系反応と、「数字が読めない」という可読性の指摘を分ける。

## End Screen

- 第一候補: 「【LINE】機種変更の前に確認！トーク履歴を残すバックアップとPIN」
- 第二候補: 「【LINE】画面が変わった？『友だちはどこ？』新しいトーク・ホームをやさしく解説」
- 目的: 更新不能ケースでの機種変更準備、またはLINEの画面に迷った視聴者を関連動画へつなぐ。

## 再判定条件

2026-09-10 Apple Eventで大きなiPhone変更が発表された場合は、公開順・タイトル・冒頭のOS説明を人間が再判定する。LINE公式ページの更新があった場合は、数字・日付・descriptionを先に更新する。
