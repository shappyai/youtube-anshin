# Episode 016 shotlist

## 撮影判断

- 状態: Phase A / 未撮影
- 主媒体: スマートフォン
- 第一候補: 個人情報を含まないAndroid Emulator上の安全なテスト用LINE環境
- 補助候補: 安全なテスト用iPhone。iPhoneとAndroidでメニュー名が違う場合は、実際に撮影した端末の表示を正とする。
- 使用禁止: 個人の本番LINE、実際の友だちとのトーク、実写真、通知、連絡先、電話番号、メールアドレス、QRコード、ログイン情報
- AI画面: LINE画面の再現にAI生成画像を使わない。UIは実際のLINE画面だけを使用する。
- Phase Aの範囲: 画面取得・実操作は行わない。削除ボタンは押さない。
- 安全な環境が作れない場合: 本番アカウントへ切り替えずHuman Gateへ報告する。架空UIで代替しない。

## 画面表示の原則

- 全体画面は場所を理解するために2〜4秒だけ見せる。
- 内容を読ませる場面は、対象項目を大きくクロップする。
- 65歳以上を想定し、画面上の情報文字は原則44px以上、主要な操作箇所は60px以上を確保する。
- 「キャッシュ」「トーク履歴」「写真・動画・ファイル」などを同じ色・同じ意味の箱に入れない。
- 画面の実際の表示名が台本と違う場合は、実機の表示を優先し、台本とshotlistをHuman Gateで更新する。
- 削除前の確認箇所を見せ、タップ後のデータ消失結果はPhase Aで作らない。

## 公式ページを使う場合の代替

安全なテスト用LINE環境が用意できず、実機画面を取得できない場合は、本番アカウントを使わない。LINE公式ヘルプの短い説明文を、LINEの実画面と誤認しないrenderer-nativeの説明カードとして使えるかHuman Gateで判断する。

代替カードは、公式UIを再現した画像や架空の設定画面にしない。カードに入れるのは「キャッシュ削除でもトーク履歴などは削除されないと公式が案内」「トークごとの容量順を確認できる」といった短い事実だけにし、URLと詳細は概要欄へ置く。

## 後工程の確認点

- AndroidとiPhoneで、入口・項目名・選択方式・確認ダイアログを比較する。
- LINEのバージョン差がある場合、動画内で「表示は端末やバージョンで異なる場合があります」と短く説明する。
- 公式情報間の注意を省略しない。キャッシュ削除後に保存期間経過メディアやアプリ内メディアが利用できなくなる場合があるため、「何も消えない」と表示しない。
- 実操作を行う場合は、Humanが対象データ・保存先・復元可否を確認した後に限る。Phase Aでは実施しない。
