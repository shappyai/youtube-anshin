# Episode 016 台本

## 制作メモ

- 状態: Phase A / Human Gate 1待ち
- 想定尺: 4分45秒〜5分45秒
- ナレーター: VOICEVOX「剣崎雌雄」ノーマル（Phase Bで生成）

- 表示文字: 画面には結論・数字・操作箇所だけを大きく出す。長いURLや細かな条件は概要欄へ分ける。

## 0. 冒頭

**ナレーション**

LINEが最近重い、容量が大きいと感じても、いきなり写真やトークを消す必要はありません。

先に、LINEの中で何が容量を使っているかを確認します。

今日は、まず見る場所を3つに絞ります。

1つ目は、LINEのデータの削除画面です。

2つ目は、キャッシュです。

3つ目は、容量の大きいトークルームです。

ただし、確認したからといって、必ずスマホが速くなるとは限りません。原因を見てから、消してよいものだけを考えます。

## 1. LINEの容量の内訳を確認する

スマホで写真を撮ろうとしたとき、空き容量が少ないと表示され、LINEの写真を消そうか迷うことがあります。

このとき、スマホ全体の容量と、LINEアプリが使っている容量は、まず分けて考えます。

LINEの中では、キャッシュやトーク関連のデータがたまると、アプリの容量が増え、動作が重くなる要因になると公式が案内しています。

最初に見るのは、削除ボタンではありません。容量の内訳です。

[SHOT-01] LINEを開き、ホームから設定を開きます。

次に、トーク、データの削除へ進みます。

ここで表示された項目と容量を、まず確認します。

スマホやLINEのバージョンによって、表示名や並ぶ順が異なることがあります。実際の画面に出ている文字を優先します。

この段階では、まだ何も削除しません。大きい項目が分かるだけでも、写真を全部消すという判断を避けられます。

もしLINEを確認してもスマホ全体の空き容量が少ない場合は、端末のストレージも別に確認します。LINEだけが原因とは限りません。

## 2. キャッシュを確認する

次はキャッシュです。

キャッシュとは、次に表示しやすくするために一時的に保存されるデータのことです。財布の中身ではなく、使い終わったレシートを一時置きする場所に近いものです。

LINE公式は、キャッシュがたまっているときに、キャッシュを削除する手順を案内しています。

[SHOT-02] データの削除画面で、キャッシュの項目を大きく見せます。

公式ヘルプでは、キャッシュを削除しても、トーク履歴などは削除されないと案内されています。

一方で、保存期間が過ぎた写真や動画は見られなくなる場合があります。また、別の公式案内では、キャッシュ削除後にLINEアプリ内の画像、動画、ボイスメッセージが見られない、または再生できない場合があると説明されています。

そのため、「キャッシュなら何も消えない」とは言いません。

削除する場合も、画面でキャッシュだけが選ばれていることを確認します。トーク履歴、写真、動画、ファイルなどをまとめて選ぶ、すべてのデータを削除する、という操作は別です。

[SHOT-03] キャッシュの選択箇所を拡大し、削除ボタンを押す前で止めます。

今回の動画では、実際のデータ削除は、安全なテスト環境で内容を確認したあとに限ります。本番のLINEで、試しに押すことはしません。

なお、アルバムのキャッシュとアルバムの中身も別です。公式ヘルプでは、アルバムのキャッシュを削除しても、アルバムの内容は削除されないと案内されています。ただし、アルバムの中身を消した場合は復元できません。

## 3. 容量の大きいトークを確認する

最後は、トークルームごとの確認です。

[SHOT-04] ホームから設定、トーク、データの削除へ進み、「トークごとにデータを削除」を表示します。

この画面では、データ容量の大きいトークルームから順に確認できると、公式ヘルプに案内されています。

ここで大切なのは、大きい順は「消す順番」ではなく、「調べる順番」の候補だということです。

大きなトークを開くと、トーク履歴、写真、動画、ファイル、ボイスメッセージなど、確認するデータが分かれて表示されることがあります。

[SHOT-05] 個人名や実際の会話を出さず、テスト用のトークルームで項目だけを確認します。削除ボタンは押しません。

大切な写真や動画がある場合は、先に保存先を考えます。公式は、受信した画像をLINEアルバムに保存する方法を案内しています。動画やファイルは、保存先と対象を確認してから判断します。

トーク内の写真、動画、ファイル、ボイスメッセージ、トーク履歴を削除すると、復元できないものがあります。削除したデータを、あとから元に戻せるとは考えないでください。

「大きいから消す」ではなく、「何が大きいのか」「残したいものはないか」「削除後に戻せるか」を確認してから、必要な場合だけ判断します。

機種変更前のバックアップと復元を扱ったEpisode 006とは、目的が違います。今回のテーマは、今のLINEの容量を調べ、整理する前に影響を確認することです。バックアップがあるから、何でも削除してよいという意味ではありません。

## 4. まとめ

今日の確認は3つです。

1つ目、LINEのデータの削除画面で、容量の内訳を見る。

2つ目、キャッシュを確認し、削除する場合もキャッシュだけを選ぶ。

3つ目、トークごとのデータを大きい順に確認し、写真やファイルを消す前に残すものを決める。

キャッシュ、トーク履歴、写真、動画、ファイル、ボイスメッセージ、アルバムの中身は、同じものではありません。

削除する前に、画面の項目と、消える可能性のあるものを確認してください。

この動画では、確認する場所を案内しました。実際の削除は、表示内容を確かめ、安全なテスト環境で内容を確認してから行います。
