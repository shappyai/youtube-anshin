## LINE公式情報

### SRC-001 キャッシュの削除とは？（重いLINEを軽くする方法）

- URL: https://help.line.me/line/smartphone/sp?contentId=20005079&lang=ja
- 組織: LINEヤフー株式会社 / LINEヘルプセンター
- 確認日: 2026-09-08
- 確認できたこと:
  - キャッシュデータやトーク履歴データが蓄積すると、LINEアプリの容量が増え、LINEが重くなったり動作が遅くなったりする要因になる。
  - ホーム → 設定 → トーク → データの削除 → キャッシュの削除、という入口が案内されている。
  - キャッシュデータを削除しても、トーク履歴などは削除されないと案内されている。
  - ただし、保存期間が経過した写真や動画などは閲覧できなくなる場合がある。
  - トーク履歴や画像データを削除した場合は復元できないと案内されている。
- Episode 016での扱い: キャッシュとトーク履歴を混同しない。キャッシュ削除を「何も消えない」と断定しない。削除前の注意として使用する。

### SRC-002 トークルーム内のデータを削除するには？

- URL: https://help.line.me/line/smartphone/pc?contentId=20010180&lang=ja
- 組織: LINEヤフー株式会社 / LINEヘルプセンター
- 確認日: 2026-09-08
- 確認できたこと:
  - ホーム → 設定 → トーク → データの削除から、項目を選んで削除する入口が案内されている。
  - 「トークごとにデータを削除」では、データ容量の大きいトークルーム順に確認できる。
  - トークルームごとのデータ削除へ進む入口も案内されている。
  - 削除したデータは復元できないと明記されている。
- Episode 016での扱い: 大きい順の一覧は「確認する順番」の参考であり、「消すべき順」とは言わない。Phase Aでは削除操作を実行しない。

### SRC-003 画像・動画・ボイスメッセージを送信・受信・再生できない

- URL: https://help-o.line.me/line/smartphone?contentId=20000236&lang=ja
- 組織: LINEヤフー株式会社 / LINEヘルプセンター
- 確認日: 2026-09-08
- 確認できたこと:
  - 端末の空き容量が少ない場合、空き容量を確保する案内がある。
  - 画像・動画・ボイスメッセージにはLINE側の保存期間があり、期間経過後は画像を見られない、動画やボイスメッセージを再生できない場合がある。公式ページでは一律の保存期間を断定していない。
  - LINEの設定画面からのキャッシュ削除や、キャッシュ削除アプリの利用により、LINEアプリ内に保存された画像・動画・ボイスメッセージが閲覧・再生できなくなる場合があると案内されている。
  - 受信した画像はLINEアルバムへの保存を検討する案内がある。
- Episode 016での扱い: 写真・動画・ボイスメッセージはキャッシュとは別に注意する。大切なものを保存する前に削除しない。保存期間の具体的な日数は言わない。

### SRC-004 アルバムの作り方・編集と、アルバム内の写真・動画を共有・転送する方法

- URL: https://help.line.me/line/smartphone/sp?contentId=20000248&lang=ja
- 組織: LINEヤフー株式会社 / LINEヘルプセンター
- 確認日: 2026-09-08
- 確認できたこと:
  - ホーム → 設定 → アルバム → すべてのアルバムのキャッシュを削除、という別の入口が案内されている。
  - アルバムのキャッシュを削除しても、アルバムのコンテンツは削除されないと案内されている。
  - アルバムのコンテンツやアルバム自体を削除した場合は復元できないと案内されている。
- Episode 016での扱い: アルバムのキャッシュとアルバムの中身を区別する補足に限定する。アルバム整理を別の4つ目の項目へ広げない。

### SRC-005 大掃除は家だけじゃない！年末こそやりたい「LINEの大掃除」

- URL: https://guide.line.me/ja/features-and-columns/cleanup-line.html
- 組織: LINEヤフー株式会社 / LINEみんなの使い方ガイド
- 確認日: 2026-09-08
- 掲載更新日: 2025-11-18
- 確認できたこと:
  - キャッシュは一時的なデータで、蓄積するとLINEが重くなったり動作が遅くなったりする場合がある。
  - キャッシュ削除の対象に、写真・動画・ボイスメッセージ・ファイルは含まれないと説明している。
  - キャッシュ削除と、写真・動画などのデータ削除は別の操作として説明されている。
- Episode 016での扱い: キャッシュの説明を日常語へ言い換える根拠として使う。ただしSRC-001とSRC-003の注意も同時に表示・ナレーションする。

### SRC-006 LINEで問題が発生した場合の対処方法

- URL: https://help.line.me/line/smartphone?contentId=20000199&lang=ja&p=faq.html
- 組織: LINEヤフー株式会社 / LINEヘルプセンター
- 確認日: 2026-09-08
- 確認できたこと:
  - LINEの問題への対処として、端末の再起動、LINEのアップデート、LINEのキャッシュ削除、不要なアプリやデータの整理などが案内されている。
  - 端末の空き容量について、2GB以上あるか確認する案内がある。
  - iPhoneとAndroidで端末ストレージの確認場所が異なる。
- Episode 016での扱い: LINEアプリの容量とスマホ全体の空き容量を切り分ける補足に使う。2GBを「速くなる保証」や全端末共通の基準にはしない。
