# Episode 001 公開前チェックリスト（人間確認用）

公開作業を始める前に、以下の項目をすべて確認する。すべて ✅ になるまで公開しない。

## 動画本体
- [ ] final.mp4 を **PC** で通し視聴（映像・音声・字幕）
- [ ] final.mp4 を **スマホ** で通し視聴（文字の読みやすさ・音量）
- [ ] 字幕が読める（72px・下部帯・最大2行・UIと重ならない）
- [ ] UI文字が読める（全体画面は短く、説明箇所は拡大されている）
- [ ] 音量が適切（小さすぎず大きすぎず・音割れなし）
- [ ] 個人情報・テストアカウント情報が映り込んでいない
- [ ] モザイク漏れがない
- [ ] 発話と字幕のタイミングが合っている
- [ ] チャプター位置と実際の内容が一致している

## メタデータ
- [ ] タイトル（候補5案から選択・推奨案の確認）
- [ ] サムネイル（final/thumbnail.png を使用・小さくして見ても読めるか）
- [ ] 概要欄（冒頭2〜3行で内容が伝わるか・5項目・注意・公式URL・クレジット）
- [ ] **ナレーション：VOICEVOX:剣崎雌雄** が概要欄に入っている
- [ ] チャプターリスト（はじめに〜まとめ）
- [ ] タグが必要最小限か
- [ ] 固定コメントの内容

## YouTubeアップロード時
- [ ] 最初は **非公開**（または限定公開）でアップロード
- [ ] アップロード後の自動字幕・画質（1080p）・音声が正常か
- [ ] サムネイルのアップロード後表示
- [ ] 概要欄のリンクが正しく表示されるか
- [ ] 非公開・限定公開での最終確認が終わってから公開を判断

## 公開後の運用（参考）
- [ ] 固定コメントを設定
- [ ] コメント欄の監視（質問・次回テーマの収集）
