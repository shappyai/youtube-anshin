# Script — Googleアカウント安全点検（v0.2）
# 制作メモ（読み上げない）: ナレーション目安は1分あたり約240字（ゆっくりめ）。想定尺は約10分（2550字）。画面名称は撮影当日に実機で再確認する。一次情報は2026-08-29時点のGoogle公式ヘルプ（sources.md参照）。

## 0:00 はじめに
Googleアカウントは、GmailやYouTube、Googleフォトなど、すべてにつながっています。
パスワードを一度変えたから安心、とは限りません。
今日は、まず確認したい5項目を、Google公式の案内をもとに見ていきます。

## 0:25 1. セキュリティ診断
1つ目は、セキュリティ診断です。「セキュリティ」は「安全」という意味で、診断は「点検」のことです。
[SHOT-01]
まず、Googleアカウントの画面を開いてください。スマホなら、右上のプロフィール写真やアカウントのアイコンから開けます。パソコンも同じです。
「セキュリティとログイン」という項目をタップし、「セキュリティ診断」と表示されている場所を開きます。画面の名前は、端末や時期によって変わることがあります。
Google公式の説明では、この診断では、あなたのアカウントに必要なおすすめの対策だけが表示されるとされています。特におすすめがなければ、その項目自体が表示されません。
表示された項目は、一度に全部やらなくて大丈夫です。まずは内容を読んで、今の自分に必要かどうかを確認してください。
推奨される対応をすべて終えると、ページの上部に緑色の盾が表示される、と公式の説明にあります。これがひとつの目印です。
この点検は一度やれば終わりではなく、定期的に、たとえば季節が変わるたびに、確認するのがおすすめです。

## 2:20 2. 再設定用の電話番号・メール
2つ目は、再設定用の電話番号とメールアドレスです。「再設定」は「もう一度設定し直す」という意味です。画面によっては、少し違う名前で表示されることもあります。
[SHOT-02]
これは、ログインできなくなったときに、あなた本人だと確認してアカウントを取り戻すための連絡先です。
Google公式の説明では、この連絡先には3つの役割があるとされています。1つ目は、第三者が勝手にアカウントを使うのを防ぐこと。2つ目は、不審な動きがあったときに通知すること。3つ目は、ログインできなくなったときに復元することです。
ですから、古い電話番号や、もう使っていないメールアドレスが残っていると、いざというときに困ります。スマホを買い替えて番号が変わった人は、新しい番号に更新してください。
知らない連絡先が入っていると感じたら、慌てて消す前に、アカウントのほかの安全情報も含めて確認してください。

## 4:00 3. 2段階認証とパスキー
3つ目は、ログインの方法です。
[SHOT-03]
Google公式は、2段階認証という方法で、アカウントの安全を強化できると案内しています。2段階認証とは、パスワードに加えて、もうひとつの確認を求める方法です。たとえば、スマホに届く確認コードを入力する方法です。パスワードを知られても、スマホが手元になければログインできない、というしくみです。
また、現在はパスキーという方法もあります。パスワードの代わりに、指紋、顔認証、スマホの画面ロックでログインする方法です。
ここで大事なのは順番です。2段階認証をオンにする前に、さきほどの再設定用の連絡先が最新であることを確認してください。公式の説明でも、再設定用の情報が完全かつ最新であることを確認するよう案内されています。たとえばスマホをなくしたときは、再設定用のメールアドレスがあればログインできる場合があります。その準備が、先に必要です。
2段階認証の設定では、バックアップコードという予備のコードも作れます。スマホが使えないときにログインするためのコードです。印刷や保存ができ、安全な場所に保管します。人に見せたり、写真に撮って送ったりしないでください。

## 6:10 4. 心当たりのない端末
4つ目は、このアカウントを使っている端末です。端末というのは、スマホやパソコンのことです。
[SHOT-04]
Googleアカウントの「お使いのデバイス」から、「デバイスを管理」を開きます。画面によっては「すべてのデバイスを管理」と表示されます。
公式の説明では、現在ログインしているか、過去数週間にログインしたデバイスが、ここに表示されるとされています。
スマホを買い替えた人は、以前の端末が表示されることがあります。それ自体は珍しいことではありません。同じ端末が複数に分かれて表示されることもあります。
見るべきは、まったく心当たりのない端末です。もし見つけた場合は、公式の案内では「デバイスに心当たりがない場合」を選び、画面の手順に沿ってアカウントを保護する、とされています。
なお、表示される場所は、おおよその地域の場合があります。場所だけで判断せず、端末の種類や日時も確かめてください。

## 7:50 5. Googleでログインしたサービス
最後は、Googleアカウントとつながっているアプリやサービスです。
[SHOT-05]
「Googleでログイン」という機能を使うと、新しいアプリやサイトに、パスワードを打たずにログインできます。それ自体は便利な機能です。
ただし、昔一度だけ使ったサービスや、何かの手続きで登録したサービスが、そのまま残っていることもあります。
Google公式の説明では、こうした接続は、いつでも確認・変更できるとされています。セキュリティの画面にある「アカウントにアクセスできるアプリ」や「サードパーティとの接続」という場所から確認できます。「サードパーティ」は「ほかの会社」という意味です。
一覧を見て、今も使っているかどうかを確認してください。
ここで注意です。名前が分からないからといって、全部をすぐに削除しないでください。削除すると、そのサービスにログインできなくなる場合があります。
分からないサービスは、先にサービス名を調べてから判断しましょう。

全部を一度にやる必要はありません。まずは、自分のアカウントに見覚えのないものがないかを、この機会に確認してみてください。
