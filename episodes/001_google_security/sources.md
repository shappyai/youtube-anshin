# Sources — Googleアカウント安全点検

確認日: 2026-08-29
※ 下記はすべて確認日当日に Google ヘルプセンター（日本語版）の本文を直接確認済み。

## 1. セキュリティ診断を受ける
- URL: https://support.google.com/accounts/answer/12629482?hl=ja
- Type: Google公式（アカウント ヘルプ）
- Confirmed:
  - 「Google アカウントを安全に保つため、定期的にセキュリティ診断を受けましょう」と案内されている。
  - 「Google アカウントのチェックリスト」（全6項目）の1つ目として位置づけられている。

## 2. アカウントのセキュリティを強化する
- URL: https://support.google.com/accounts/answer/46526?hl=ja
- Type: Google公式（アカウント ヘルプ）
- Confirmed:
  - セキュリティ診断で、そのアカウントに応じた「おすすめのセキュリティ対策」を確認できる。
  - 「推奨される対応」が表示されない場合、Google からのおすすめのセキュリティ対策はない、と記載。
  - すべての推奨事項を完了すると、ページ上部に緑色の盾が表示される、と記載。
  - 再設定用の電話番号とメールアドレスは、①第三者が許可なくアカウントを使うのを防ぐ ②不審なアクティビティを通知する ③ログインできなくなった場合に復元する、ために使われる、と記載。
  - パスキーは指紋認証・顔認証・スマートフォンの画面ロック（PIN など）でログインできる、と記載。

## 3. 2 段階認証プロセスによる個人情報の保護
- URL: https://support.google.com/accounts/answer/10956730?hl=ja
- Type: Google公式（アカウント ヘルプ）
- Confirmed:
  - 2 段階認証は、パスワードに加えて2つ目の確認手順（スマートフォン・セキュリティキー・印刷されたコードなど）を求める方法。パスワードを盗まれても、スマートフォンが手元になければ悪用できない、と記載。
  - バックアップ コード（スマートフォンを使用できない場合にログインできる一時コード）をダウンロードまたは印刷して安全な場所に保管できる、と記載。
  - スマートフォンを紛失した場合は、登録済みの再設定用メールアドレスを使用してログインできる場合がある、と記載。
  - 2 段階認証の FAQ で「再設定用の情報が完全かつ最新の状態であることを確認する」よう案内されている。

## 4. パスワードの代わりにパスキーでログインする
- URL: https://support.google.com/accounts/answer/13548313?hl=ja
- Type: Google公式（アカウント ヘルプ）
- Confirmed:
  - パスキーは指紋認証・顔認証・スマートフォンの画面ロック（PIN など）で Google アカウントにログインできる方法。
  - パスキーを使ったログインでは2つ目の手順が省略される場合がある、と記載。

## 5. アカウントにアクセスしたデバイスを確認する
- URL: https://support.google.com/accounts/answer/3067630?hl=ja
- Type: Google公式（アカウント ヘルプ）
- Confirmed:
  - 「お使いのデバイス」パネルで「すべてのデバイスを管理」を選ぶと、現在ログイン中または過去数週間にログインしたデバイス・セッションが表示される、と記載。
  - 同じ種類のデバイスで複数のセッションが表示されることがあり、それだけでは不正利用と判断できない、と記載。
  - 表示される場所は「正確な場所ではなく、付近の場所」の場合がある、と記載。

## 6. ハッキングまたは不正使用された Google アカウントを保護する
- URL: https://support.google.com/accounts/answer/6294825?hl=ja
- Type: Google公式（アカウント ヘルプ）
- Confirmed:
  - 心当たりのないデバイスを見つけた場合、「デバイスに心当たりがない場合」を選択し、画面上の手順に沿ってアカウントを保護する、と記載。
  - 再設定用の電話番号・メールアドレス・氏名など重要な設定への覚えのない変更がないか確認するよう案内されている。

## 7. 「Google でログイン」を使用する
- URL: https://support.google.com/accounts/answer/12629094?hl=ja
- Type: Google公式（アカウント ヘルプ）
- Confirmed:
  - ユーザー名とパスワードを入力せずにアプリやサイトへログインできる機能と説明されており、信頼できるアプリやサービスにのみアクセスを許可するよう注意を促している。
  - 「これらのアプリのアクセス権限は、いつでも更新できます」と記載。

## 8. サードパーティとの接続を管理する
- URL: https://support.google.com/accounts/answer/16363505?hl=ja
- Type: Google公式（アカウント ヘルプ）
- Confirmed:
  - サードパーティ製のアプリやサイトと共有した情報はユーザー自身で管理でき、接続は Google アカウントからいつでも変更できる、と記載。
  - フィルタを使うと「Google でログイン」でログインしているアプリと、Google ドライブへのアクセスなど権限を付与したアプリを確認できる、と記載。
