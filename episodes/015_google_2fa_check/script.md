# Episode 015 script

## 基本情報

- 仮タイトル：【Google】2段階認証していても確認したい3か所
- 対象：すでにGoogleの2段階認証を設定している人。特に65歳以上の視聴者
- ナレーター：VOICEVOX「剣崎雌雄」ノーマル（speedScale 1.00 / intonationScale 1.00 / pitchScale 0.00）
- Phase B：full draft Human Gate待ち
- 想定尺：4〜6分。音声生成後の実尺で確認する

## 制作メモ（読み上げない）

- 2段階認証は重要な対策であり、無効化を勧める動画ではない。設定内容を確認して、今も使える状態にする。
- viewer-facingの見出しは、正式なGoogle UI名称より先に日常語を使う。正式名称は画面表示・補足で示す。
- Episode001の「再設定用の電話番号・メール」「ログイン中の端末」「接続済みアプリ」「セキュリティ診断」など、Googleアカウント全体の広い点検は繰り返さない。
- バックアップ コードは入口と存在だけを見せる。コードの数字、保存場所、個人情報は録画・静止画・字幕に残さない。新規作成や更新はしない。
- 個別アカウントの設定画面は、認証済みのテスト用セッションが用意できた場合だけ実画面を追加する。現段階のfallback画面は、公式UI名称の確認カードとして扱い、実アカウント画面とは呼ばない。
- 「方」は自然な代替表現がある場合に使わない。固有のUI名称・引用以外は、発音レビューで確認する。

## 本編

### 導入

**[SEG-001]** Googleの2段階認証を設定していても、確認しておきたい場所があります。

**[SEG-002]** 2段階認証は、パスワードに加えて、もう一度本人確認をする大切な対策です。

**[SEG-003]** ただ、設定したときから時間がたつと、確認に使うスマホや予備の方法が、今の生活と合わなくなっていることがあります。

**[SEG-004]** 今日は3か所だけ一緒に確認します。

**[SEG-005]** 見るのは、いつもの確認方法、スマホが使えないときの予備、登録されているパスキーの3つです。

**[SEG-006]** 2段階認証を外すのではなく、今も自分が使える設定かを確かめていきましょう。

### 1 / 3　いつもの確認方法

**[SEG-007]** 1 / 3、いつもの確認方法です。

**[SEG-008] [SHOT-01]** Googleアカウントを開き、「セキュリティとログイン」を選びます。

**[SEG-009]** 「Googleにログインする方法」の中から、「2段階認証プロセス」を開きます。

**[SEG-010] [SHOT-02]** ここでは、パスワードのあとに、何で本人確認する設定なのかを確認します。

**[SEG-011]** 表示される内容は、アカウントによって異なります。スマホへの通知、確認コード、認証アプリなどが表示されることがあります。

**[SEG-012]** 今使っているスマホや方法と、画面の登録内容が合っているかを見比べます。

**[SEG-013]** 古いスマホや、もう使っていない方法が残っている場合は、すぐに削除せず、まず現在の確認方法が使えることを確かめます。

**[SEG-014]** 見覚えのない表示があっても、この画面だけで不正利用と決めつける必要はありません。Google公式の案内を確認し、分からない操作は止めておきましょう。

**[SEG-015]** Googleからのメッセージが表示されたら、端末・場所・時刻を確認します。自分の操作なら「はい」、違う操作なら「いいえ」を選び、分からないときは公式の案内を確認します。

### 2 / 3　スマホが使えないときの予備

**[SEG-016]** 2 / 3、スマホが使えないときの予備です。

**[SEG-017]** バックアップ コードは、スマホが手元にないときなどに、本人確認へ使える予備のコードです。

**[SEG-018] [SHOT-03]** 「2段階認証プロセス」の中にある、「バックアップ コード」を開きます。

**[SEG-019]** ここで確認するのは、コードを用意してあるか、そして自分が安全な場所を分かっているかです。

**[SEG-020]** Google公式では、バックアップ コードは10個のコードからなる新しいセットを作成でき、1つのコードは1回だけ使えると案内されています。

**[SEG-021]** 新しいセットを作ると、以前のセットは使えなくなります。今回は確認だけにして、作り直しはしません。

**[SEG-022]** 以前に保存した場所が分からない場合は、そのコードがあるつもりで進めないことが大切です。必要なら、落ち着いて公式の案内を確認してから対応します。

**[SEG-023]** 新しいコードを作るかどうかは、保存する場所を先に決めてから考えます。紙に保管する場合も、他人に見せない場所を選びます。

**[SEG-024]** バックアップ コードは、電話やメールで誰かに伝えるものではありません。画面にコードの数字が出ても、録画やスクリーンショットには残さないでください。

**[SEG-025]** Googleが電話でバックアップ コードを聞くことはありません。求められても伝えず、公式サイトから確認します。

### 3 / 3　登録されているパスキー

**[SEG-026]** 3 / 3、登録されているパスキーです。

**[SEG-027]** パスキーは、スマホやパソコンの画面ロック、指紋、顔認証などを使って、パスワードの代わりにログインする方法です。

**[SEG-028]** パスキーを使うと、場合によっては2段階目の確認を省いてログインできます。これは、2段階認証をオフにすることとは別の仕組みです。

**[SEG-029]** 大事なのは、自分が持っていて、画面ロックをかけている端末にだけ登録されているかを確認することです。

**[SEG-030] [SHOT-04]** Googleアカウントの「パスキーとセキュリティ キー」の場所を開きます。

**[SEG-031]** Androidスマホでは、端末の設定などによって、パスキーが自動的に登録されることがあります。表示された端末名を確認します。

**[SEG-032]** 今も自分が使っている端末なら、そのままで構いません。古い端末や共有の端末があれば、登録を見直します。

**[SEG-033]** 新しく登録するときは、自分が所有し、画面ロックを設定している端末だけを使います。

**[SEG-034]** 使っていない端末を見つけた場合も、名前だけで判断せず、公式の説明を確認してから削除を考えます。

**[SEG-035]** パスワードを使わずにログインする設定が表示される場合もあります。内容を理解していないまま、変更を急がなくて大丈夫です。

**[SEG-036]** パスキーは便利な方法ですが、登録先を確認して、自分の端末だけになっているかを見ておきましょう。

### まとめ

**[SEG-037]** まとめです。1つ目、いつもの確認方法。

**[SEG-038]** 2つ目、スマホが使えないときの予備。

**[SEG-039]** 3つ目、登録されているパスキーとセキュリティ キー。

**[SEG-040]** 2段階認証は大切な対策です。そのうえで、確認に使う方法と予備の手段を、今の自分に合わせておきます。

**[SEG-041]** 見覚えのない表示があっても、慌てて削除や変更をせず、Google公式の案内を確認しましょう。

**[SEG-042]** 設定が確認できたら、今日はここで終わりです。
