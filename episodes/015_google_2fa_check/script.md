# Episode 015 script

タイトル（暫定）：**【Google】2段階認証していても確認したい3か所**  
ナレーター：VOICEVOX「剣崎雌雄」ノーマル（Phase Bで生成）  
調査日：2026-09-08  
想定尺：4〜6分（VOICEVOX実測前の暫定）

## 制作メモ（読み上げない）

- 2段階認証を否定しない。「重要な対策。そのうえで設定内容を確認する」が一貫した立場。
- 冒頭4セグメントで結論と「今日は3か所だけ一緒に確認します」まで入れる。
- Episode 001のセキュリティ診断、再設定用連絡先、一般的な端末一覧、接続済みアプリは本編で繰り返さない。
- 今回の3項目は、①現在の確認方法、②バックアップ コード、③登録済みパスキーとセキュリティ キー。
- 実際の認証コード、バックアップ コード、メールアドレス、電話番号、アカウント名は映像に出さない。
- 画面の表示名・導線は撮影当日にテストアカウントで確認し、違いがあれば実画面を正本にする。
- 「方」は自然な代替表現がある箇所で使わない。`今日は`、`Google`、`2段階認証`、`Google認証システム`、`バックアップ コード`、`パスキー`、`セキュリティ キー`はVOICEVOX発音レビュー対象。

## はじめに

**[SEG-001]** Googleの2段階認証を設定していても、確認しておきたい場所があります。

**[SEG-002]** 2段階認証は、パスワードに加えて、もう一つの確認を求める重要な対策です。

**[SEG-003]** そのうえで、以前登録した確認方法が、現在も使えるかを見ておきます。

**[SEG-004]** 今日は3か所だけ一緒に確認します。

**[SEG-005]** 見るのは、現在の確認方法、バックアップ コード、登録済みパスキーの3つです。

**[SEG-006]** どれも、設定を変える前に、まず表示を確かめるだけで大丈夫です。

## 1 / 3　現在の確認方法

**[SEG-007]** 1 / 3、2段階認証プロセスの、現在の確認方法です。

**[SEG-008] [SHOT-01]** Googleアカウントを開き、「セキュリティとログイン」を選びます。

**[SEG-009]** 「Googleにログインする方法」の中から、「2段階認証プロセス」を開きます。

**[SEG-010] [SHOT-02]** ここでは、パスワードのあとに、何で本人確認する設定なのかを確認します。

**[SEG-011]** Googleからのメッセージ、確認コード、Google認証システムなど、表示される内容はアカウントによって異なります。

**[SEG-012]** 自分が現在使っているスマホや方法と、画面の登録内容が合っているかを見てください。

**[SEG-013]** 機種変更で古いスマホを手放した人は、古い方法や電話番号が残っていないかも確認します。

**[SEG-014]** ただし、表示された名前だけで不正利用と決めつける必要はありません。分からなければ、変更せずに公式ヘルプを確認します。

**[SEG-015]** Google公式では、確認コードを入力するより、Googleからのメッセージをタップする方法をおすすめしています。

**[SEG-016]** 通知が届いたら、表示された端末、場所、時刻を確かめて、自分の操作なら「はい」を選びます。

**[SEG-017]** 自分が操作していない通知なら、「いいえ」を選び、次の対応は公式の案内で確認します。

## 2 / 3　バックアップ コード

**[SEG-018]** 2 / 3、バックアップ コードです。

**[SEG-019]** これは、スマートフォンを使えないときの、2段階認証の予備の入口です。

**[SEG-020] [SHOT-03]** 同じ「2段階認証プロセス」の画面で、「バックアップ コード」を開きます。

**[SEG-021]** コードが用意されているか、保管場所を自分が分かっているかを確認します。

**[SEG-022]** Google公式では、バックアップ コードは10個の新しいセットを作成でき、1つのコードは1回だけ使えると案内されています。

**[SEG-023]** 新しいセットを作ると、古いセットは自動的に無効になります。

**[SEG-024]** 昔ダウンロードしたコードが、紙やファイルのどこにあるか分からない場合は、古いものをそのまま頼りにしないでください。

**[SEG-025]** 新しいセットを作るなら、先に保管場所を決めて、安全にしまいます。

**[SEG-026]** コードそのものは、動画や写真、メールで人に渡さないでください。

**[SEG-027]** Googleが電話でバックアップ コードを聞くことはない、と公式に案内されています。

## 3 / 3　パスキーとセキュリティ キー

**[SEG-028]** 3 / 3、パスキーとセキュリティ キーです。

**[SEG-029]** パスキーは、パスワードの代わりに、スマホの画面ロックなどでログインする方法です。

**[SEG-030]** 2段階認証を設定しているアカウントでも、パスキーでログインすると、2つ目の確認が省略されます。

**[SEG-031]** これは、2段階認証をオフにしたという意味ではなく、パスキーが別のログイン手段として使われるということです。

**[SEG-032] [SHOT-04]** Googleアカウントの「パスキーとセキュリティ キー」を開き、登録されているものを確認します。

**[SEG-033]** Google公式では、Android端末にこのアカウントでログインしていると、パスキーが自動で登録されている可能性があると案内しています。

**[SEG-034]** 表示された端末が、自分の持ち物で、現在も使っているものかを確認してください。

**[SEG-035]** パスキーは、自分が所有して使う端末にだけ作成するよう、Googleが案内しています。

**[SEG-036]** 古い端末を手放した場合や、共有の端末に作ってしまった場合は、Googleアカウントから削除できます。

**[SEG-037]** ただし、名前だけで判断せず、端末の買い替え時期や自分の記憶も照らし合わせてから操作します。

**[SEG-038]** 「可能な場合はパスワードをスキップする」という設定があれば、パスキーを優先する設定かどうかも確認できます。

## まとめ

**[SEG-039]** まとめです。1つ目、2段階認証で現在使う確認方法。

**[SEG-040]** 2つ目、スマートフォンが使えないときのバックアップ コード。

**[SEG-041]** 3つ目、別のログイン手段であるパスキーとセキュリティ キー。

**[SEG-042]** 2段階認証は重要な対策です。そのうえで、登録内容を確認して、現在の自分で使える状態にしておきます。

**[SEG-043]** 分からない表示があったら、削除や変更を急がず、Googleアカウントの公式画面とヘルプで確認します。

**[SEG-044]** 再設定用の連絡先やログイン中の端末も大切ですが、今回はそこを詳しく繰り返さず、2段階認証の周りに絞りました。

**[SEG-045]** 設定が確認できたら、今日はここで終わりです。
