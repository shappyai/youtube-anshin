# Episode 009 brief

## 企画

- エピソード: 009
- 仮タイトル: 【Windows 11】このままで大丈夫？10月13日までに確認したいこと
- テーマ: Windows 11 version 24H2のサポート終了と、一般ユーザーが今確認すること
- 制作段階: Phase A（一次情報・台本・scene設計・Visual Gate前まで）
- 基準日: 2026-09-05（公開前に公式ページを再確認）
- 想定尺: 本編4:30〜5:30、CTAは後工程で共通CTAを追加
- 視聴者: 50〜70代、特に65歳以上。Windows Updateに詳しくない家庭ユーザー

## 企画判断

Windows 11の「全部が終了する」という誤解を最初にほどき、Home / Proなどの24H2だけが対象であることを伝える。視聴者が自分で行う確認を、①バージョン、②Windows Update、③表示されない場合の考え方、の順に固定する。

「10月13日」を入口にするが、買い替えを急がせる構成にはしない。25H2の提供時期には機器差があり、セーフガードホールドもあるため、表示されないことを故障と断定しない。26H1は既存PC向けの通常の更新先ではないため、検索結果で混乱しないよう短く整理する。

## 注意する誤解

- Windows 11全体が2026-10-13に使えなくなる、とは言わない。
- 24H2のHome / Pro等とEnterprise / Education / LTSCを同じ終了日として扱わない。
- 25H2がすぐ表示されないことを故障・買い替え必須と断定しない。
- 26H1を既存PCへ手動インストールするよう勧めない。
- 現在の制作PCはWindows 10 Pro 24H2なので、Windows 11の実機画面として使わない。
