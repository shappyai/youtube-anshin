# Episode 009 research report

確認日: 2026-09-05

## 結論

Microsoft公式の対応表では、Windows 11 version 24H2のHome / Pro / Pro Education / Pro for Workstationsは、2026-10-13に更新の提供終了となる。これはWindows 11全体の終了ではなく、エディションとバージョンを分けて確認する必要がある。Enterprise / Education / LTSC等は別のサポート期間を持つ。

## 主要事実

### 1. 24H2の終了日

Microsoft LearnのWindows client supported versionsとWindows 11 release informationを突合した。一般家庭でよく使われるHome / Proの24H2は、2026-10-13が更新終了日である。supported versionsの表ではPro Education、Pro for Workstationsも同じ列に含まれる。24H2のHome / Proで終了後に起きることとして、Microsoftの24H2 statusページは、既知の問題修正、タイムゾーン更新、技術サポート、月次セキュリティ・プレビュー更新が提供されなくなると説明している。

「その日を過ぎた瞬間に起動しない」「Windows 11全部が終了する」とは確認できないため、台本では言わない。Enterprise / Educationや長期サービスチャネルは別表・別期間なので、家庭向けの説明に混ぜない。

### 2. 25H2の確認

Microsoftは、管理されていないHome / Proの24H2端末に対して、対象となる場合は25H2を自動提供すると説明している。設定のWindows Updateで更新プログラムを確認すると、準備できた端末では「Windows 11 version 25H2」のダウンロードとインストールが表示される。25H2の提供は段階的で、アプリ・ドライバーの既知の互換性問題がある端末にはセーフガードホールドが設定される場合がある。

したがって「25H2が表示されない = 故障」「表示されない = 今すぐ買い替え」とは言えない。まず現在の更新を適用し、再起動して、時間を置いて再確認する。手動ISOやUpdate Assistantによる強制更新は、一般ユーザー向けの今回の基本手順にしない。

### 3. 26H1の扱い

26H1は、Microsoftが2026年の一部の新しい機器向けに用意した特別なリリースで、既存PCへWindows Updateで提供されず、既存PCへインプレースで導入するものではない。24H2 / 25H2の年次更新と同じ一般的な更新先として説明しない。検索で26H1を見かけても、24H2のユーザーがまず確認するのは25H2である。

### 4. 一般ユーザーの確認手順

Microsoft Supportの案内に合わせて、次の2画面を扱う。

1. スタートを右クリック > 設定 > システム > バージョン情報。Windowsの仕様でエディションとバージョンを見る。
2. 設定 > Windows Update。更新プログラムの確認を選ぶ。

個人名・メールアドレス・デバイスID・プロダクトID等が表示される場合があるため、実機captureを行う場合は公開前にマスキングする。公式素材は個人情報を含まない見出しcropだけをPhase Aで採用した。

## 不確実性・公開前チェック

- official pages are live pages and may be updated. 公開直前に、2026-10-13、対象エディション、25H2の提供説明を再確認する。
- 実機captureはWindows 11のテスト端末で再撮影できる場合にだけ差し替える。現在のPCはWindows 10 Pro 24H2であり、Windows 11 UI撮影には使わない。
- `Windows 11 version 24H2`という表記、`25H2`、`26H1`の英数字は表示字幕で読み仮名に変えない。VOICEVOX用の読みは後工程で音声QAする。

## 競合・需要の扱い

競合動画は本調査の根拠に使用していない。需要仮説は「終了日だけを見ると不安になるが、一般ユーザーが自分の画面で確認できる3手順にすると理解しやすい」。タイトルは終了を断定する形を避け、「このままで大丈夫？」「確認したいこと」で落ち着いた入口にする。
