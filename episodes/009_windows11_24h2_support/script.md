# Episode 009 台本

## タイトル案

**【Windows 11】このままで大丈夫？10月13日までに確認したいこと**

制作基準日: 2026-09-05

想定尺: 本編4:30〜5:30。VOICEVOX、字幕タイミング、draft動画はPhase Bで作成する。ここでは読み上げる本文と画面指示だけを確定する。

## 0:00 はじめに — 結論と今日確認する3つ

[SHOT-01]

Windows 11を使っている方、2026年10月13日に、一部のWindows 11で更新の提供が終わります。

ただし、Windows 11全部が、その日に使えなくなるわけではありません。

今日は、自分のパソコンで確認したい3つを、順番に見ていきます。

[SHOT-02]

一つ目、自分のWindowsのバージョンです。

二つ目、Windows Updateの画面です。

三つ目は、更新が表示されないときに考えるポイントです。

## 1:08 1 / 3 — まず、自分のバージョンを確認

[SHOT-03]

最初に、安心してほしいことです。

今回、2026年10月13日に更新の終了とされているのは、Windows 11のうち、バージョン24H2のHome、Pro、Pro Education、Pro for Workstationsです。

これは、Windows 11全体が10月13日に終了する、という意味ではありません。

EnterpriseやEducationなどは、サポート期間が異なります。

家庭でよく使われるHomeやProの方は、まず自分のバージョンを確認しましょう。

[SHOT-04]

画面左下のスタートボタンを右クリックします。

設定を開き、システム、バージョン情報の順に進みます。

下のほうにある、Windowsの仕様を見てください。

[SHOT-05]

ここで見るのは、エディションと、バージョンです。

バージョンが24H2か、25H2かを確認します。

画面は、パソコンによって少し違うことがあります。

[SHOT-06]

実際の画面では、システムの中にあるバージョン情報を開きます。

個人名やIDが見えている場合は、動画や人に見せる前に隠してください。

[SHOT-07]

デバイスの仕様という見出しの下で、Windowsの仕様を探します。

この確認は、24H2かどうかを知るためのものです。

## 1:55 2 / 3 — Windows Updateを確認

[SHOT-08]

二つ目は、Windows Updateです。

設定から、Windows Updateを開きます。

[SHOT-09]

更新プログラムの確認を選びます。

更新が準備できている場合は、Windows 11 version 25H2のダウンロードとインストールが表示されます。

[SHOT-10]

表示されたときは、作業中のファイルを保存して、案内を読みながら進めます。

再起動を求められることがあります。

更新の表示やタイミングは、すべてのパソコンで同じではありません。

## 2:52 3 / 3 — 表示されないときの考え方

[SHOT-11]

三つ目は、25H2が表示されないときです。

表示されないからといって、故障とは限りません。

アプリやドライバーとの相性を確認するため、Microsoftが一時的に更新を保留することがあります。

これを、セーフガードホールドといいます。

無理にISOファイルなどを使って、手動で更新することはおすすめしません。

[SHOT-12]

ここで、検索すると出てくる26H1についても、短く説明します。

26H1は、2026年の新しい一部の機器向けに用意された、特別なリリースです。

いま使っている24H2のパソコンが、26H1へ更新されるわけではありません。

Microsoftは、26H1を既存のパソコンへWindows Updateで提供しないと説明しています。

[SHOT-13]

24H2の場合は、まず25H2が表示されるかを確認してください。

まずは、いまのWindows Updateを最新の状態にします。

パソコンを再起動し、少し時間を置いて、もう一度確認します。

[SHOT-14]

それでも分からないときは、Microsoftの公式サポートや、パソコンメーカーに相談しましょう。

会社や学校で管理されているパソコンは、管理者の案内を優先してください。

## 3:55 困ったとき — サポート終了の意味

[SHOT-15]

サポート終了とは、10月13日を過ぎた瞬間にパソコンが使えなくなる、という意味ではありません。

ただし、HomeやProの24H2では、その後、通常のセキュリティ更新などを受けられなくなります。

対応するバージョンへ更新することが大切です。

10月13日までに、慌ててパソコンを買い替えましょう、という話ではありません。

[SHOT-16]

まず、バージョンを確認し、Windows Updateを確認する。

これが、いま行う順番です。

## 4:29 まとめ

[SHOT-17]

最後に、今日の3つです。

一つ目、自分のWindowsのバージョンを確認する。

[SHOT-18]

二つ目、Windows Updateで更新プログラムを確認する。

三つ目、表示されないときは、慌てず、無理な手動更新をしない。

[SHOT-19]

不安なときは、公式サポートや詳しい人に相談してください。

役に立ったら、チャンネル登録して、次回も一緒に確認しましょう。

## 事実境界・音声メモ

- `2026-10-13` は、対象エディションの更新終了日として説明する。すべてのWindows 11が終了するとは言わない。
- 25H2の表示時期は端末により異なる。表示されないことを故障・買い替え必須としない。
- 26H1は既存PC向けの通常の更新先として案内しない。
- `Windows 11`、`24H2`、`25H2`、`26H1`、`Windows Update`、`ISO`、`Pro Education`、`Pro for Workstations`は、VOICEVOX生成前に読み方を確認する。表示字幕へ読み仮名を流出させない。
- Phase Aでは音声を生成しない。CTAの声は後工程で`channel_common_cta`のcanonical textと合わせる。
