# Episode 012 analytics plan

実験名: `long_form_watchtime_v1`  
対象: Episode 012の公開後データ。テーマが異なるため、Episode 002 / 010 / 011との比較は準実験として扱う。

## 成功指標

最重要は **平均視聴時間（AVD）** と総再生時間。視聴維持率（APV）だけを上げるために短くしない。8〜12分の実用動画として、視聴者が5場面と共通3手順を持ち帰れるかを評価する。

| 指標 | 見る理由 | 記録単位 |
|---|---|---|
| views / unique viewers | 到達と重複視聴 | 公開後7日・28日 |
| watch time hours | 長尺化の総量効果 | 公開後7日・28日 |
| watch time / 1,000 views | クリック後の価値 | 公開後7日・28日 |
| AVD / APV | 長尺実験の主指標 | 公開後24h・7日・28日 |
| retention | 冒頭と各ケースの落ち方 | 0:30 / 3:00 / 5:00 / 8:00 / 終了 |
| subscriber conversion | CTAの負担と再訪理由 | subscribers gained / unique viewers |
| subscribers / 1,000 unique viewers | 視聴者規模に依存しない登録効率 | 公開後7日・28日 |
| returning viewers | 次回も確認したいか | 7日・28日 |
| end screen CTR | まとめからの次視聴 | 公開後7日・28日 |
| Browse / Search | タイトルと実用需要の差 | 流入比率 |
| audience 65+ / TV | 主要視聴者への適合 | YouTube Analyticsの取得可能範囲 |

## 既存尺との比較基準

- Episode 002: **7:56**。これまでの長尺寄りの基準。
- Episode 010: **約3:39**。短めの比較。
- Episode 011: **約4:15**。直近の実績。
- Episode 012: Phase A推定 **約10:46**、draft_v4/final実測 **585.400秒（9:45.4）**。内容追加・無音追加は行わず、この実尺を基準値にする。

再生数の単純比較は行わず、同じ公開後経過日数でAVD、総再生時間、1,000再生あたり総再生時間、冒頭30秒維持、5章の章間離脱を比較する。データが未取得の項目は推測せず `null` と記録する。

## 観察仮説

1. 「本物を見分ける」ではなく「リンクから入らず公式を開く」を20秒以内に示すと、冒頭離脱を抑えられる。
2. 5ケースを同じ手順で追うことで、1ケース目だけでなく後半まで実用情報が続くと理解され、AVDが短尺回を上回る。
3. 中盤CTAを宅配ケース後に1回だけ置くことで、長尺の視聴体験を大きく中断せず登録導線を作れる。
4. ケース名を変えても同じ行動を繰り返すため、重複感が出た地点を章別Retentionで確認する。

## 人間確認項目

公開後にタイトル・サムネの約束と実際の5ケースが一致しているか、視聴者コメントに「公式のどこを開くか分からない」が増えていないかを確認する。Apple Event（2026-09-10 JST）でiPhoneの安全設定や詐欺対策に大きな更新が発表された場合は、公開順と概要欄のリンクを人間が見直す。
