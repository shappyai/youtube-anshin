# Episode 012 description

いつも使っている会社や公的機関の名前で、「支払い方法を更新してください」「再配達はこちら」「カードの利用を確認してください」「料金が未払いです」などのSMSやメールが届くことがあります。

この動画の結論は、メッセージだけで本物かどうかを当てる必要はない、ということです。メール・SMSのリンクから入らず、自分で公式アプリや公式サイトを開いて、通知・注文履歴・利用明細・請求額・公式のお知らせを確認します。

5つの場面で確認します。
1. 通販・普段使うアプリの支払い更新
2. 宅配・再配達
3. クレジットカードの利用確認
4. 携帯会社・通信料金の未払い
5. 役所・公的機関を装うお知らせ

Case 1は国民生活センターが2026年9月3日に公表した相談例を、掲載された範囲で紹介します。その他の説明sceneは公式注意喚起をもとにした意味図解です。実在のメールアドレス、URL、電話番号、QRコード、個人名、アカウント番号は使用しません。

困ったときは、消費者ホットライン188などの公式相談先を自分で調べて連絡してください。リンクを開いた、ID・パスワードを入力した、カード情報を入力した、口座・送金情報を伝えた、アプリを入れた、では対応が異なります。
