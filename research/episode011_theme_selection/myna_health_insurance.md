# A：スマートフォンのマイナ保険証

確認日：2026-09-05（日本時間）

## まず区別する3つ

「スマホのマイナ保険証」は、次の3つを分けて説明しないと誤解が起きる。

| 用語 | 意味 |
|---|---|
| マイナンバーカードの健康保険証利用登録 | マイナンバーカードを健康保険証として使うための登録 |
| スマートフォンのマイナンバーカード | マイナンバーカードの機能をスマートフォンへ追加するサービス |
| スマートフォンのマイナ保険証 | 健康保険証利用登録済みのカードをスマートフォンに追加し、対応する医療機関・薬局で受診する使い方 |

スマートフォンへのカード追加だけで、健康保険証利用登録まで済むとは扱わない。

## 公式に確認できる利用条件

厚生労働省の公式案内では、スマートフォンのマイナ保険証は2025年9月19日から、準備の整った医療機関・薬局で順次利用できる。

利用前に必要なもの：

- 対応機種のスマートフォン
- 最新のマイナポータルアプリまたは現行のマイナアプリ案内
- 実物のマイナンバーカード
- iPhoneでは券面事項入力補助用暗証番号4桁
- 署名用パスワード英数字6〜16文字
- 健康保険証の利用登録。すでにマイナ保険証を使っている人は不要

利用できる医療機関・薬局は、公式の対応施設検索で事前に確認する。掲載施設でも当日に利用できない場合や、掲載反映にタイムラグがあると公式に書かれている。視聴者に「どの病院でも使える」と言わない。

## 受付の流れ

公式の利用手順を、動画企画上の確認順に並べると次のとおり。

1. 顔認証付きカードリーダーで「スマートフォンを利用」などのボタンを選ぶ。
2. iPhoneまたはAndroidを選ぶ。
3. 本人認証をする。
4. 近くのスマホ用汎用カードリーダーにスマートフォンをかざす。
5. 画面が切り替わったら、顔認証付きカードリーダーで同意情報を入力する。

### iPhone

Appleウォレットを開き、マイナンバーカードが表示されていることを確認して、Face IDまたはTouch IDで認証する。Face ID搭載機ではサイドボタンのダブルクリック、Touch ID搭載機ではホームボタンの操作が公式案内に記載されている。

### Android

顔認証付きカードリーダーに、スマートフォンへ追加するときに設定した、スマホ用利用者証明用電子証明書の4桁暗証番号を入力する。

次の3つは別物である。

- スマホ用電子証明書の4桁：入力する
- スマートフォンのロック解除番号：入力しない
- 実物のマイナンバーカード用電子証明書の4桁：入力しない

認証後、スマホ用汎用カードリーダーから少し離した状態で、1〜2秒ほどかざす。機器によってかざす場所が異なる場合があるため、実機撮影時は施設の案内を優先する。

## 数字の扱い

確認できた公表資料には次の数字がある。ただし日付を付けて表示する。

- 2026-06-07時点のスマートフォンのマイナンバーカード登録数：8,022,119
- 2026-03-29時点のスマートフォンのマイナ保険証対応施設集計：125,047施設

これらは2026年9月時点の最新値ではない。公開時に使うなら、資料の日付を必ず併記し、現在値のように見せない。

## C1の詐欺電話との接続

厚生労働省は、職員を装い、健康保険証利用登録を音声案内に従って行わせる詐欺電話を確認した。厚生労働省が電話の音声案内やSMSで、直接利用登録を要求することは一切ない。

視聴者に伝える確認軸：

1. 電話やSMSの案内だけで登録を始めない。
2. 暗証番号・マイナンバーを口頭で答えない。
3. 自分で公式サイト、正規アプリ、医療機関の窓口を開いて確認する。
4. 答えてしまった場合は0120-95-0178、不審な場合は110番または＃9110へ相談する。

制度説明Aと詐欺確認C1は関連するが、動画の中心を混ぜすぎない。C1をEpisode 011にする場合は、受付手順を長く説明せず、詐欺との境界を明確にする。

## Aの動画化評価

### 強み

- 病院という具体的な場面で、自分事化しやすい。
- iPhone／Androidの違いを実機で説明できる。
- 「対応施設を事前確認」「実物カードも持つ」という安心行動がある。
- C1、B、E010への関連動画導線を作れる。

### 弱み

- 開始から約1年で、一般的な使い方動画は公式・ニュース・大手解説が多い。
- 対応施設・アプリ名・OS条件の更新があり、撮影後に古くなる可能性がある。
- 「スマホだけで受診できる」と言い切ると、施設条件・同意・実物カードの注意を落とす。

### 判定

一般的な「使い方」だけなら82点。C1の確認電話という直近の公式注意喚起と接続した場合、Episode 011の最有力切り口に昇格する。
