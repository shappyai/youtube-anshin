# 登録用語マップ

確認日：2026-09-05

検索者が使う「登録」は、公式ページ上では複数の別操作を指し得る。タイトル・台本では、対象を「マイナアプリの利用登録」と明示する。

| 検索者の言葉 | 公式上の対象 | Episode 010での扱い | 混同リスク |
|---|---|---|---|
| マイナアプリ 登録方法 | マイナアプリの利用登録 | 主検索語。初回利用の一本道を扱う | 中 |
| マイナアプリ 初期設定 | マイナアプリの利用登録と初回起動時設定 | 補助語。タイトル・説明欄で併記候補 | 中 |
| マイナアプリ 使い方 | 利用登録後の機能全般 | 本編の入口には広すぎる | 高 |
| マイナポータル アプリ 変わった | 旧アプリからマイナアプリへの刷新 | 冒頭の背景説明に限定して扱う | 中 |
| マイナポータル ログイン方法 | マイナポータルへのログイン | 010では手順を扱わない。007等へ送る | 高 |
| マイナンバーカードをスマホに登録 | iPhoneのマイナンバーカード／Androidスマートフォンの電子証明書の登録 | 別企画。認証手段の説明だけに留める | 高 |
| スマホ用電子証明書 登録方法 | Androidスマートフォンの電子証明書登録等 | 別企画。010の主題にしない | 高 |
| マイナンバーカード 保険証 登録 | 健康保険証利用登録 | 別企画。010から明確に除外 | 高 |
| 4桁 暗証番号 マイナアプリ | 実物カード認証で使う利用者証明用暗証番号 | 本編の注意点として扱う | 中 |
| マイナアプリ 登録できない | 読み取り・OS・ロック・暗証番号などのトラブル | 010では深掘りしない。007との重複に注意 | 高 |
| マイナアプリ Android | Android対応OS・NFC・対応機種 | OS条件の補足に限定。別動画化も可能 | 中 |
| マイナアプリ 機種変更 | 端末変更後の再設定・引き継ぎ | 別企画 | 高 |

## タイトルで使う語

「登録方法」は検索入口として残し、「初めて使う」「利用登録」「流れ」のいずれかを添えると、何を登録する動画かを明確にしやすい。

## 避ける言い方

- 「マイナンバーカードを登録する方法」とだけ書く
- 「マイナポータルの登録」とだけ書く
- 健康保険証の登録まで一つの登録方法としてまとめる
- トラブル対応を含むのに、初回登録だけのように見せる
