# Short002 ImageGen-native prompt set v2

- 生成方式：built-in `image_gen`
- Use case：`photorealistic-natural`
- 共通指定：縦9:16、人物・背景・主要オブジェクト・短い見出しを一体生成。日本人シニア、自然な生活場面、スマホ表示時に読める濃紺の大見出し。追加文字、送信者名、URL、実在企業・サービスのロゴ、QR、個人情報、実在メールUI、fake UI、透かし、collage、split panel、presentation slideを入れない。見出しは画面左上〜上中段、人物・重要物・右端Shorts UI・下20%と重ねない。

## Scene 01 — hook

人物：60代後半の日本人。generic smartphoneを見て「本物？」と考える。少し困った表情だが恐怖や煽りは避け、明るい住居の自然な場面にする。画面にメール本文や読める文字を描かない。

画像内の正確な文字（2行）：

```text
このメール、
本物？
```

## Scene 02 — privacy mask

人物：60代後半の日本人女性。家庭の机でgeneric smartphoneの空白の情報ブロックを手で覆う。紙もスマホも完全に抽象的な空白で、氏名・住所・電話番号・会員番号などを描かない。

画像内の正確な文字（2行）：

```text
個人情報は
まず隠す
```

## Scene 06 — official confirmation

人物：65〜70歳程度の日本人男性。generic smartphoneと無地の青いファイルを家庭の机で落ち着いて確認する。公式サイトや政府窓口の実在画面・ロゴを描かず、「公式から確認」の行動だけを表現する。

画像内の正確な文字（2行）：

```text
最後は
公式から確認
```
